# SoteOps Agent

Independent Finnish-language portfolio prototype. It prepares synthetic access requests for human review and, after approval, forwards them to a mock integration.

This is not commissioned by, affiliated with, or connected to Päijät-Hämeen hyvinvointialue. Demo data is synthetic only. The working hypothesis about reduced rework has not been validated.
